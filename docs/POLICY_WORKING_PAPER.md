# POLICY WORKING PAPER: Open School Engineering Framework (OSEF)
**Aligning Secondary School Computer Science Education with NEP 2020 & Modern Industry Requirements**

---

## Executive Summary
The secondary school Computer Science (083) and Informatics Practices (065) curricula across Indian boards continue to rely on syntax memorization and manual paper-notebook lab evaluations. Meanwhile, global software engineering has transitioned toward system design, logic auditing, and AI orchestration. 

This paper introduces the **Open School Engineering Framework (OSEF)**—an open-source, infrastructure-light secondary school curriculum designed to modernise K-12 CS education in alignment with the National Education Policy (NEP) 2020.

---

## 1. The Core Disconnect in Secondary CS Education

1. **The Syntax vs. Architecture Gap:** High school assessments prioritize paper-written syntax accuracy over algorithmic problem-solving and software architecture.
2. **The Generative AI Reality:** Modern software workflows leverage AI for syntax generation. The high-value skill has shifted from writing syntax to auditing logic, verifying security, and designing systems.
3. **Resource Constraints:** Most budget schools lack the high-end hardware, expensive subscriptions, or persistent cloud access required by modern computing platforms.

---

## 2. Policy Alignment with NEP 2020

OSEF directly addresses key mandates outlined in the **National Education Policy (NEP) 2020**:

* **Competency-Based Education (NEP Para 4.4):** Transitions evaluation from rote learning of programming syntax to demonstrable coding competence and system logic.
* **Experiential & Vocational Skill Integration (NEP Para 16.1):** Introduces real-world industry tools (Git version control, REST APIs, local database schemas) starting from Class 9.
* **Low-Cost Infrastructure Focus (NEP Para 24.4):** Designed specifically for offline, low-spec computer lab environments using lightweight local Small Language Models (SLMs) and self-hosted local LAN Git servers.
